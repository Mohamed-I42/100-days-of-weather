# 100-days-of-weather
Project idea ---> Weather data visualisation using Java and Processing

Question: What patterns can I identify through 100 days of weather?

Planned Data:
Day number
Weather Type
Temperature
Wind Level

OBJECTIVE: To create a 10 x 10 grid of weather symbols, using different colours and shapes to represent different weather conditions.

Data Method:
The dataset contains 100 simulated weather records, using weather types, temperatures and wind levels.
